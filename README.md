# PitchZone

Application Shark Tank pour classe de Bac Pro Métiers de la Vente.

## Déploiement Render

1. Fork ce repo ou importer l'URL
2. Build Command : `npm install`
3. Start Command : `npm start`
4. Variable d'environnement : `ANTHROPIC_API_KEY` = ta clé API

## Accès
- Professeur : `/prof.html`
- Élèves : `/eleve.html`
